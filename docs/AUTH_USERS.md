# Пользователи SpyService

Миграция `db/migrations/006_users_and_private_settings.sql` создаёт таблицы пользователей,
серверных сессий и персональных зашифрованных настроек. Она также создаёт пользователя
`admin` с паролем `логин12344321!`.

## Создание дополнительного пользователя вручную

1. Сгенерируйте безопасный хеш пароля в папке проекта:

   ```bash
   pnpm auth:hash-password 'Длинный-уникальный-пароль'
   ```

2. Скопируйте всю полученную строку `scrypt$v1$...` и выполните в phpMyAdmin:

   ```sql
   INSERT INTO users (username, password_hash, display_name, role)
   VALUES ('alexey', 'ВСТАВЬТЕ_SCRYPT_ХЕШ', 'Alexey', 'user');
   ```

Пароль открытым текстом в MySQL не записывается. Чтобы отключить доступ, установите
`is_active = 0`; все действующие сессии можно завершить удалением строк пользователя
из `user_sessions`.

## Перенос старых данных браузера

При первом входе новый клиент отправляет старый случайный `clientId` и сохранённые
локально OpenAI/Google-реквизиты. Сервер переносит связанные коллекции, избранное,
заметки, AI-отчёты и прокси в область данных вошедшего пользователя, шифрует секреты,
после чего браузер очищает старое локальное хранилище.
